# Example posts

Drop 10–20 posts here whose style you want the drafts to copy: your own best posts,
or posts by others you admire. One post per `.md` file, e.g. `linkedin-missed-calls.md`.

Every `.md` file in this folder except this README is included in the drafting prompt,
so remove any that drift from the voice you want.

`visuals/` holds design references (images plus notes on why they work). They are not
sent to Claude with every draft; they guide the visual templates in
`src/content_agent/visuals/templates/`.
